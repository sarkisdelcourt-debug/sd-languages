# Voix intégrées

Enregistrements générés avec [Piper](https://github.com/rhasspy/piper) (MIT) à partir des voix libres de
[rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) :

- Anglais : `en_GB-alba-medium` — jeu de données de l'Université d'Édimbourg, licence CC BY 4.0
  (https://datashare.ed.ac.uk/handle/10283/3270).
- Allemand : `de_DE-thorsten-medium` — Thorsten-Voice, licence CC0.
- Espagnol : `es_ES-davefx-medium` — licence CC0.

Régénération : `npx tsx scripts/generate-audio.mts` (voir l'en-tête du script pour les outils requis, hors dépôt).
